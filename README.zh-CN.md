# 格林布鲁克研习院 · Greenbrook Institute（第一人称 3D 版 · 英文版）

把原来的「平面阅读体」互动叙事，改成了 **第一人称 3D**。
3D 只做一处——**爱德华·班克斯在二楼的那个房间**，但尽量把这一个房间做满细节：
书桌上摊开的日记、父亲的棕色皮箱、母亲的润喉糖、床头那本没有作者署名的《玻璃侦探》、
插销在外侧的窗、衣柜、镜子、一九五三年九月的日历……你在房间里第一人称走动、查看，
而桌上的日记一翻开，**完整的分支剧情**（五章 +《玻璃侦探》+ 出院报告）就从头开始。

> 纯前端，无需后端。用 Three.js 做这一个房间，叙事仍由原来的阅读界面承载。

**英文版说明**：游戏里玩家能看到的全部文字（五章正文与选项、《玻璃侦探》、出院报告、
手术通知信、封面与界面、3D 房间里的物件提示和旁白）都已译成英文；剧情分支、选项条件、
存档键与所有逻辑保持不变，旧存档可以直接继续。字体换成英文字体（见下表 `fonts/`），
逐字显示的速度按英文字符数等比例调整，整段文字和写字声的时长与中文版一致。

## ▶ 怎么玩

**操作**

| 操作 | 按键 |
| --- | --- |
| 行走 | `W` `A` `S` `D`（或方向键） |
| 环顾 | 移动鼠标（需先点击画面锁定指针） |
| 交互 | `E` 或 鼠标左键（准星对准发亮的物件） |
| 释放指针 / 暂停 | `Esc` |

**目标**：在房间里走动、查看各处细节；走到书桌前**翻开日记**，故事就从这里开始写。

**运行（推荐用本地静态服务器）**

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> WebGL / 指针锁定 / 音频在 `http://` 下最稳。直接双击 `index.html`（`file://`）
> 多数浏览器也能跑，但个别浏览器会限制指针锁定或纹理加载，故推荐用上面的服务器方式。
> 任意静态托管（GitHub Pages / Netlify / Vercel / 自己的服务器）把整个目录原样上传即可。

## 🧭 设计：交互逻辑，以及如何贴合这个剧情

原作是一篇关于「一个人的语言与心智如何被一点点抹掉」的文学恐怖——爱德华·班克斯
一九五三年来到「研习院」（其实是精神病院）教书，每晚饭后那粒「润喉糖」般的白色
小圆片，最后的「神经外科评估」（脑叶切除），让他从开篇繁复深邃的文字，一路坍缩到
「吃。睡。冷。」，再到空白。

**为什么 3D 只做这一个房间。** 这个房间是他写日记、被一寸寸抹掉的地方——是整部作品
的「现场」。与其铺一整栋楼，不如把这一处做满：让每一件 1953 年的日常器物都落到原作的
细节上，让你在动手翻开日记之前，先在这个房间里待一会儿，闻到它的气味。

**房间里可查看的东西（都对应原作的细节）：**
- **桌上的日记** → 翻开它，进入完整阅读层（叙事主体）。
- **床头的《玻璃侦探》** → 那本没有作者署名、与他处境互为镜像的小说。
- **父亲的棕色皮箱** → 提手被父亲的手掌焐出的形状，「两代人的手在一段皮革上的握手」。
- **母亲的润喉糖** → 与每晚那粒白色小圆片「两种薄荷味，一深一浅」的并置。
- **窗户** → 凑近会发现：插销在外侧；光「只贴在玻璃表面亮着，进不来」。
- **镜子** → 「镜子里是我。或者说，是一个长得像我的人。」
- **《荒原》/ 衣柜 / 日历 / 房门** → 艾略特、七件衬衫、九月七日、门外那条走廊。

**房间的细节（英文版第二轮打磨）。** 只加看得见的东西，交互逻辑、提示文字、旁白、音效、碰撞范围一概没动：
- 建模：墙裙护墙板与腰线、檐口、天花水渍、褪色地毯；书桌上方一排旧书；曲木椅、带铜拉手的抽屉；
  铁床的竖栏与圆头床柱；会开门的衣柜（里面七件照颜色叠好的衬衫、两条挂着的长裤、一套睡衣）；
  带皮带、铜扣、铜包角的皮箱，提手那一段颜色更深、更亮；脸盆与水壶、毛巾；会走秒针的闹钟；
  带「枫叶牌」纸标签、看得见里面白色小圆片的润喉糖瓶；门边挂钩上的大衣与礼帽；门缝里透进走廊的灯。
- 镜子是真的会照出房间的反射，只是照不出你自己；银层发暗剥落，剧情越往后越照不清。
- 窗：玻璃上有水珠和往下淌的雨痕，窗帘有褶、会轻轻晃；插销在玻璃外侧看得见、够不着；
  闪电时能看见远处的屋脊和一棵秃树。
- 交互反馈：准星对准任何物件都会微微发亮；台灯开关渐亮渐暗、灯链会晃；衣柜门会打开再关上；
  药瓶、《荒原》、日历、门把手各有一个小动作。
- 皮箱会打开：点一下，两把锁扣先弹开，箱盖绕后沿的合页翻起来（开到头被两根拉带拽住、回弹一下），
  箱口扬起一小团灰，在灯光里亮一下再慢慢沉下去；里面是褪了色的酒红条纹里衬、两条松着的捆衣带，
  盖子内侧的侧兜里插着入院时签的那几页文件。过几秒箱盖自己合上、锁扣扣回去。旁白和音效照旧。
- 性能：阴影只在物件动过之后才重算；程序贴图改用 CPU 画布生成；从首页「继续」直接进桌面时，
  3D 房间等回到房间时才加载，桌面不会被房间的加载卡住。

**凋零度（decay）把两层缝在一起。** 剧情每往后一章，房间就更冷、更暗、灯闪得更频、暖色
被一点点抽走——和文字本身从繁复坍缩到「吃。睡。冷。」同步。读得越深，回到的房间越荒。

**深层叙事仍在「阅读层」里。** 原作那一万多字的分支文本（含走廊里三个人的相遇、嵌套小说、
脑叶切除的信、最终的报告），价值正在于它的文学密度；3D 负责把你放进房间、放到桌前，
文字负责承载那场缓慢的抹除。

## 🛠 修改后重新构建

改了 `src/` 里的代码后才需要重建（需要 [Node.js](https://nodejs.org/)）：

```bash
npm install      # 首次安装依赖（含 three）
npm run build    # 重新生成 bundle.js 与 app.css
npm run serve    # 本地静态服务器预览
```

`npm run dev` 会先构建再起服务器。

## 💾 存档

进度自动保存在浏览器 `localStorage`（沿用原存档键，旧档可继续）。
首页「新游戏」会清空存档；「继续」会让你回到房间，接着翻开日记。
更换浏览器、使用隐身模式或清除浏览数据会丢失存档。

## ⚙ 技术说明

- 3D：Three.js（r184），手写的第一人称控制器（指针锁定 + WASD + 矩形碰撞 + 射线拾取）。
- 房间与全部家具均为**程序化几何 + 程序化贴图**（木地板、旧墙纸、日历、褪色照片……），
  不依赖任何外部 3D 资源，离线可跑。
- 界面 / 阅读层：React 19 + Motion（Framer Motion）。
- 打包：esbuild（输出传统 `<script>`）；样式：Tailwind CSS v4 预编译为静态 `app.css`。
- 所有素材均使用相对路径，可放在任意子目录或域名下运行。
